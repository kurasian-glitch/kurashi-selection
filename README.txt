くらしの選択帖 - Amazonアソシエイト向けサイト初期版

【内容】
- index.html：トップページ
- about.html：サイトについて
- privacy.html：プライバシーポリシー（公開前に内容を確認）
- contact.html：お問い合わせ（メールアドレス等の設定が必要）
- articles/：記事3本と記事テンプレート
- assets/style.css：デザイン・スマホ対応

【ローカルで確認】
index.html をブラウザで開いてください。インターネット公開前の見た目確認ができます。

【公開前に必ず行うこと】
1. お問い合わせ先を実際に受信できる連絡先に変更する。
2. 運営者情報を実態に合わせて記載する。
3. プライバシーポリシーを、導入する解析・広告ツールに合わせて更新する。
4. 記事を自分で確認・編集し、独自の経験、調査、比較表、写真等を追加する。
5. Amazonアソシエイトに登録し、承認されたトラッキングIDを使った正規リンクに差し替える。
6. Amazonの最新プログラム要件・リンク表示・商品画像利用ルールを確認する。

【重要】
このファイルはサイトの初期デザイン・記事下書きです。Amazonアソシエイトの審査通過や収益を保証するものではありません。
現在のAmazonトップページへのリンクはアフィリエイトリンクではありません。
Amazonアソシエイトの所定の開示文言を、サイト上の見つけやすい場所に正確に表示してください。
記事中の「使用した」「おすすめ」等の表現は、実際の確認・体験に基づいて編集してください。

【無料公開先の例】
静的サイトを公開できるサービス（例：GitHub Pages等）を利用できます。独自ドメインは任意ですが、無料公開先のURLでも開始できます。公開サービスの最新利用条件・規約は各公式サイトで確認してください。
